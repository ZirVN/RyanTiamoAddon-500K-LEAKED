## Hướng dẫn cài đặt (Tiếng Việt)

1. Cài đặt Fabric Loader cho Minecraft 1.21.11 (phiên bản loader 0.18.2 trở lên).
2. Tải Meteor Client (1.21.11-SNAPSHOT) và Litematica phù hợp phiên bản 1.21.11, sau đó thả vào thư mục `.minecraft/mods`.
3. Thả file `ZirAddon-1.3.6-R67.jar` (hoặc file được build ra) vào thư mục `.minecraft/mods`.
4. Mở Minecraft, mở GUI Meteor Client để bật/tắt các module của ZirAddon hoặc dùng ModMenu để cấu hình.

### Cách Build mã nguồn
Chạy lệnh sau tại thư mục gốc của dự án:

Windows:
```cmd
.\gradlew.bat build
```

Linux / macOS:
```bash
./gradlew build
```

File jar hoàn chỉnh được tạo tại: `build/libs/ZirAddon-1.3.6-R67.jar`

## Installation Guide (English)

1. Install Fabric Loader for Minecraft 1.21.11 (loader version 0.18.2 or higher).
2. Download Meteor Client (1.21.11-SNAPSHOT) and Litematica for 1.21.11, then place them inside your `.minecraft/mods` folder.
3. Put `ZirAddon-1.3.6-R67.jar` into your `.minecraft/mods` directory.
4. Launch Minecraft, open the Meteor Client GUI to configure/toggle ZirAddon modules or use ModMenu.

### Building from Source
Run the wrapper command in your project root:

Windows:
```cmd
.\gradlew.bat build
```

Linux / macOS:
```bash
./gradlew build
```

Output jar location: `build/libs/ZirAddon-1.3.6-R67.jar`
